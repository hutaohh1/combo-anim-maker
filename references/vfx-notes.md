# 打击感三件套：刀光 / 受击 / 位移 实操笔记（程序化版）

砍到敌人只是及格线——要"说服别人敌人确实被砍中了"。所有贴图和动画都用代码生成，不调外部服务；精美度靠风格化渲染 + 特效骗术。

## 一、刀光特效（slash_vfx.py）

`python scripts/slash_vfx.py --out build/vfx --color ff3040 --arc 118` 一次生成三张贴图（512×512，RGBA）：

| 层 | 文件 | 作用 | 生成要点 |
|----|------|------|----------|
| 底色层 | `slash-base.png` | 主体色块弧带 | 弧带沿弧从根部到尾部渐隐，内外缘柔边；决定颜色与轮廓 |
| 亮纹层 | `slash-streaks.png` | 高速亮线 | 数条白色弧线，从弧长 15% 处起笔——像被挥刀拖出来的 |
| 腐蚀层 | `slash-erosion.png` | 溶解遮罩 | 白=被溶解的洞；根部 25% 不开洞，向尾部洞越大越密，拖尾自然消散 |

`slash-combined.png` 是棋盘格底的叠加预览，交付前先看它确认层次。

**关键参数：** `--color` 主色（跟角色/游戏主题配色）、`--arc` 弧跨（角度）。挥得快用小弧跨，大开大合用 140°+。

**引擎里怎么用（摆位法）：**

1. 三层贴图叠在同一个面片上（或三个叠加面片），blend 用加法/透明叠加
2. 沿**武器运动的轨迹**摆放并拉长——拖尾方向必须与武器实际挥动方向一致
3. 腐蚀层作为遮罩驱动溶解进度（0% → 100%），时长与攻击动画的有效帧对齐：刀光在攻击判定帧出现，后摇前消散完
4. 2D 帧动画没有真实 3D 武器轨迹——把 2D 纸片人放进 3D 编辑空间（Godot/Unity 3D 场景或 Blender）：角色作广告牌，刀光作独立面片设大小/位置/旋转/出现时机，横版相机渲染
5. 程序化贴图是均匀弧带，**个性来自摆位与叠加时机**——同一张贴图换弧跨、换颜色、换出现帧，就是不同招式的刀光

## 二、打击感小件（preview.html 已内置，引擎等价做法）

| 小件 | 试玩页实现 | Godot / Unity 落地 |
|------|-----------|-------------------|
| hit-stop 顿帧 | 命中帧冻结 2 帧 | hit 时把动画播放速度设 0 持续 0.05~0.1s（Godot: `AnimationPlayer.speed_scale=0`；Unity: `animator.speed=0` + 协程恢复） |
| 屏幕震动 | 命中后随机偏移、指数衰减 | 相机 shake 组件/简单噪声偏移，幅度 4~8px、时长 0.15s 级 |
| 火花粒子 | 命中点喷 14 颗带重力小方块 | 粒子系统一次性 burst；颜色跟刀光主色 |
| 动态残影 | 攻击段前一帧以 28% 透明度叠加 | 引擎里用 ghost/sprite 复制 + 淡出，或烘进帧序列（本管线已烘） |
| HUD 续接提示 | 攻击进度 ≥ 窗口显示"可续接!" | 调试期强烈建议保留，验手感神器 |

这些小件是"打击感"的大头——特效贴图只是素材，小件才是手感。

## 三、受击反馈（hit_reactions.py，4 套缺一不可）

`python scripts/hit_reactions.py --image 敌人图.png --out build/ --mode cutout --hit-by <主角动作库>`

| | 轻受击（12 帧） | 重受击（24 帧） |
|---|--------|--------|
| 正面 | 原地硬直小动作 | 大后仰 + 3 步踉跄 |
| 背面 | 硬直（动画镜像） | 后仰踉跄（动画镜像） |

实现规则：

- **前 4 帧白闪**（alpha 220 → 165 → 110 → 55 渐弱）：命中瞬间最强的反馈信号
- **反应与攻击方式对应**（`--hit-by`）：被突刺打中击退深（×1.35，身体被顶直）、被重砸打中向下压垮、被挥砍打中甩头拧身狠（×1.3）、弓/枪械后坐小、徒手拧身——被长枪戳和被巨锤砸是同一种后仰，打击感就假了
- **轻受击原地做动作**，重受击后仰 + 踉跄（位移感区分打击轻重）；重击的击退位移不烘进帧——动画回到原位，位移交给引擎按 spec 执行，否则循环播放会瞬移回弹
- **背面版是正面动画的镜像近似**——对用户诚实说明；要真实背身需补一张背面参考图
- 敌人图没有时：用主角色图代替（打稻草人效果），或让用户提供
- **出血方向参数化**：动画里不烘血；每次命中按 `combo-spec.json` 的 `bloodDirections` 告诉特效系统血往哪个方向飞（如 30° 仰角、与攻击方向一致）。没有方向感的受击不可信

## 三点五、伪 3D 手段（cutout_animator.py 已内置，调参用）

纸片人要有"连起来像 3D"的错觉，靠四个程序化手段，都不要钱：

| 手段 | 实现 | 调参位置 |
|------|------|---------|
| 深度缩放 | 攻击相挥到一半武器/手臂朝镜头凸出 → 放大 6~10%，前摇向后蓄力 → 微缩 4%（透视错觉） | `_part_scale()` |
| 动态遮挡 | 挥砍/重砸前摇武器沉到躯干之下（收到身后），命中扫到身前——遮挡关系随时间变化是最强纵深线索 | `WEAPON_Z` |
| 地面软阴影 | 脚下椭圆软阴影随身体位移，接地感 | `render_frame(shadow=True)` |
| 武器运动学挂接 | 武器位移 = 前手手端绕肩的弧线位移，武器只保留绕握点自转——全程不脱手 | 主流程 `hand_off` |
| 帧内拖影 smear | 最快几帧内部把武器按子角度多重曝光 2~3 份低透明副本，画出速度弧 | 主流程 hit 相 8%~55% |
| 方向性 rim light | 朝攻击方向的边缘光（面向右→右缘），命中相最亮、前摇微亮 | `render_frame` rim 段 |
| 帧时序不等分布 | 极值处停留（1.3~1.5x）、apex 掠过（0.55x）；GIF 逐帧时长 + timing.json 交引擎 | `_dur_mul` |

常见"假"的观感多半是这四样缺了某一样，或武器挂接的握点估计歪了（看 rig-debug.png 调 rig.json）。

## 四、追击位移

详见 state-machine.md 的"位移"一节。要点复述：

- 程序化动作和视频动作一样都是**原地**的 → 给每个动画分段加位移，不要做高机动低复杂度方案
- 复杂连招的价值就在于：位移只加在关键段（如跳起转身砍），其余段原地蓄力
- 示例：第五击 49 帧拆三段 +20 / +230 / +10 px，全部写进 `combo-spec.json` 的 `displacement`

## 五、分工纪律

- **AI 的强项是编程**：本 skill 的五件套脚本就是证明；用户要"再快一点 / 火花多一点 / 换个颜色"，第一反应是改参数或现场写小工具，不是找素材
- **AI 无能为力的**：某一帧歪了几个像素、审美层的主观判断 → 让 AI 随手做调参工具（rig-debug 叠层、逐帧 tuner），**人工拍板**
- 每次交付前把 preview.html 递给用户试玩——手感是玩出来的，不是看出来的
