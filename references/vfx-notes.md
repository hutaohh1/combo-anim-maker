# 打击感三件套：刀光 / 受击 / 位移 实操笔记

来源：像素小宝实战方法（BV1ZJeU6pESc）。砍到敌人只是及格线——要"说服别人敌人确实被砍中了"。

## 一、刀光特效（attack trail / slash VFX）

网上有大量现成的 attack trail / slash VFX 素材，核心是**三张贴图叠加**：

| 层 | 作用 | 要点 |
|----|------|------|
| 底色层 | 刀光主体色块 | 火焰形/流线形色块，决定颜色与轮廓 |
| 亮纹层 | 高速亮线 | 叠加锋利的白色/亮色条纹，做出速度感 |
| 腐蚀层 | 消散遮罩 | 噪点纹理，控制拖尾逐渐溶解消失 |

**合成步骤：**

1. 三层贴图按同轨迹叠加（底色 + 亮纹）
2. 沿**武器运动的轨迹**一划拉、把拖尾拉长——拖尾方向必须与武器实际挥动方向一致
3. 腐蚀层作为遮罩逐步溶解（0% → 100%），拖尾自然消散
4. 时长与攻击动画的有效帧对齐（刀光在攻击判定帧出现，后摇前消散完）

**关键难点：2D 帧动画没有真实的 3D 武器轨迹**——2D 纸片人"划拉不起来"。

**解法：把 2D 纸片人放进 3D 编辑空间**（Godot / Unity 的 3D 场景或 Blender）：

1. 角色作为面向相机的广告牌（billboard）
2. 刀光贴图作为独立面片，设置**大小 / 位置 / 旋转角度 / 出现时机**
3. 相机回到横版视角渲染 → 得到"想象中的武器攻击轨迹"

与专门给单个动作手绘的拖尾相比有差距，但这是**完全可行的 AI 美术解法**。

素材关键词：`attack trail`、`slash VFX`、`sword slash sprite`、`刀光贴图`。

## 二、受击反馈（4 套动画 + 出血方向）

给敌人做 **4 套受击动画**，缺一不可：

| | 轻受击 | 重受击 |
|---|--------|--------|
| 正面 | 原地硬直小动作 | 大后仰 + 踉跄几步 |
| 背面 | 原地硬直（背身版） | 前扑 + 踉跄几步 |

规则：

- **轻受击原地做动作**，重受击踉跄几步（位移感区分打击轻重）
- 受击动画同样可以走"白模参考 → Seedance 换皮"管线生成
- **出血方向参数化**：每次攻击命中后，告诉 AI / 特效系统血往哪个方向飞（如 30° 仰角、与攻击方向一致）。没有方向感的受击不可信。
- 全部写入 `combo-spec.json` 的 `hitReactions` 与 `bloodDirections`

## 三、追击位移

详见 state-machine.md 的"位移"一节。要点复述：

- 动作全是原地的 → 给每个动画**分段加位移**，不要做高机动低复杂度方案
- 复杂连招的价值就在于：位移只加在关键段（如跳起转身砍），其余段原地蓄力
- 示例：第五击 49 帧拆三段 +20 / +230 / +10 px

## 四、分工纪律

- **AI 的强项是编程**：校准工具、播放时长控制、各种小功能——要啥让 AI 写，几乎 100% 能实现
- **AI 无能为力的**：某一帧歪了几个像素、人物身体比例不协调
- 解法：让 AI 随手做**大大小小的调参工具**（如逐帧缩放/偏移的 Frame Tuner），**人工手动微调**
- 本 skill 展示的是思路，实际更麻烦的是编程——所以更要善用 AI 写代码
