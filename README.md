# 游戏连招动画生成器（combo-anim-maker）

> 一个通用 Agent Skill：**给 AI 一张角色图，还你一套横版游戏里"能打"的连招动画。** 纯本地程序化生成——零外部调用、零积分、离线可用。任何支持 Agent Skills 开放标准（SKILL.md）的 AI 助手都能安装使用。

## 这个 skill 是干什么的？

一句话：**把"三段式拆解 + 状态机组装"这套连招设计方法，固化成一条纯本地、可反复迭代的生成流水线。**

你要做横版动作游戏，需要一个角色的连招：按一下打一下、连按有连段、砍到敌人有受击反馈。你试着直接让 AI"生成一段连招动画"——得到的是一整串漂亮但**没法玩**的视频：不能停、不能断、不能接你的操作。本 skill 把它工程化成一条程序化流水线，并配上**双击即玩的试玩页**来验收手感。

## 它凭什么能行？四个关键思路

| 思路 | 一句话解释 |
|------|-----------|
| **三段拆解** | 绝不一次生成整条连招！按「前摇→攻击→后摇」分段设计与合成，才可能做成交互连招 |
| **程序化渲染** | Python+Pillow 抠图切件、关键帧插值逐帧合成，描边/光影/残影提升质感；切件不齐就整图模式，宁整勿碎 |
| **特效骗术** | 代码画刀光三层贴图、程序化受击四套（白闪+踉跄）、hit-stop/震屏/火花——精美度靠风格化，不靠烧积分 |
| **状态机组装** | 攻击进度 ≥50% 才能续接、后摇可被打断、不按就停；7 个边界用例自动自检 + 试玩页实测手感 |

## 快速上手（3 步）

1. **触发**：在你的 AI 助手（Agent）里说 ——
   - "给我的角色做一套连招动画"
   - "帮我做横版游戏的攻击动作，要带打击感"
   - "把这张角色图做成能打的游戏动画"
2. **配合**：给一张角色图（绿幕/纯色底最佳）→ 确认段数/武器/风格 → 看 rig 调试图和 GIF 提意见 → 试玩 preview.html 验手感
3. **收货**：拿到 `角色名-combo-pack.zip`（帧序列 + sprite sheets + 刀光贴图 + 受击动画 + combo-spec.json + 试玩页），导入 Godot / Unity 按 spec 接线即可

## 你会得到什么

```
我的角色-combo-pack.zip
├── frames/          每段帧序列 PNG（描边 + 渐变光影 + 攻击段残影）
├── sheets/          每段 sprite sheet（引擎导入用）
├── vfx/             刀光三层贴图（底色层/亮纹层/腐蚀层）
├── hit-reactions/   敌人受击动画 4 套（正面/背面 × 轻/重，带白闪）
├── rig.json         部件比例配置（可微调后重跑）
├── combo-spec.json  连招规格：段数/续接窗口/位移/出血角度/贴图路径
├── preview.html     双击即玩的连招试玩页（J 键出招，内置状态机+打击感小件）
└── README.txt       导入说明（Godot AnimationPlayer / Unity Animator 接线提示）
```

## 前提条件

- 一个支持 **Agent Skills 开放标准**的 AI 助手（Claude Code、Cursor、Codex CLI 等——SKILL.md 是通用开放格式，放进对应技能目录即被自动发现）
- **Python 3 + Pillow**（`pip install pillow`）——唯一依赖，全程离线
- 目标引擎：Godot / Unity（其他引擎照搬 spec 参数也行）
- Windows / macOS / Linux 均可

## 安装

把整个 `combo-anim-maker/` 文件夹放进你的 AI 助手的技能目录，任选其一：

| 你的工具 | 技能目录 |
|----------|----------|
| 通用标准（多家工具共用，推荐） | `~/.agents/skills/combo-anim-maker/` |
| Claude Code | `~/.claude/skills/combo-anim-maker/` |
| 其他工具 | 见各工具文档中的 skills 目录，把文件夹整个放进去即可 |

也可以直接**对话安装**：把本仓库的 zip 拖进你的 AI 助手对话，说"帮我安装这个连招动画 skill"。

## 与 AI 视频生成的关系（可选进阶）

默认管线**不需要任何 AI 视频服务**。如果你追求照片级写实的换皮效果、且有可用的视频生成服务（如 Seedance / 即梦），skill 内置了进阶模式：找 3D 白模动作做参考视频 → AI 视频换皮 → 后续分段、状态机、特效流程完全一致。风格化 / 剪影 / 像素赛道（独立游戏的主流选择）走默认程序化管线即可。

## FAQ

**Q：为什么不能直接让 AI 生成连招？**
A：直接生成的是"一整串动画"，游戏需要的是可交互的动作系统。三段拆解 + 状态机才是"游戏感"的来源。

**Q：一定要用 AI 视频生成吗？**
A：不用。v2 默认管线纯本地程序化生成，零积分、可无限迭代；只有照片级写实换皮才需要（进阶可选模式）。

**Q：角色图切出来部件歪歪扭扭的？**
A：看 AI 给你的 rig-debug 调试图，调 rig.json 重跑；构图特殊的角色（极简/Q版）直接用整图模式，观感更完整。

**Q：段数越多越爽吗？**
A：不。视频原话"量力而行"：空洞骑士 2 段（还靠倒放）、月之诅咒 1 段。默认 2~3 段，5 段封顶。

**Q：敌人数值也要状态机吗？**
A：不用。敌人出招直接整串播放（`mode: "enemy"`），打击感靠受击反馈补。

**Q：生成的动作是原地的，怎么打到人？**
A：给关键动作分段加位移（如第五击 +230px 的跳砍），连招自动具备追击能力。
